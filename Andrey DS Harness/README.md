# Andrey DS Harness V 0.5.3

Копия DeepSeek Harness с собственным слоем `lib/andrey` (загружается через
`resources/app/package.json` → `main: lib/andrey/boot.cjs`). Правки в этом каталоге
применяются сразу: `resources/app` распакован, asar пересобирать не нужно — только
перезапустить приложение.

## Дизайн

Пункт **«Дизайн»** в меню «…» (и `Ctrl+Shift+D`) открывает полноэкранный редактор
канваса: прямоугольники, эллипсы, текст, перо, выделение, перемещение, ресайз,
цвета, слои, undo/redo, несколько документов и автосохранение.

- Горячие клавиши: `V` выделение, `H` рука, `R` прямоугольник, `O` эллипс, `T` текст,
  `P` перо; `Space` + перетаскивание — панорама; колесо — зум к курсору;
  `Delete` удалить, `Ctrl+D` дублировать, `Ctrl+Z` / `Ctrl+Shift+Z` отмена/повтор,
  `Ctrl+S` сохранить, `Esc` закрыть панель.
- Документ: `~/.config` не используется — файлы в `%APPDATA%\andrey-ds-harness\design\<id>.json`
  (переопределяется `ANDREY_DATA_ROOT`). Хранится до 50 документов, запись атомарная.
- Модель для ИИ берётся из текущего выбора в чате; если имя неоднозначно (есть у обоих
  провайдеров), в селекте панели показывается суффикс провайдера.

### API (только loopback)

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/design/docs` | список документов |
| GET | `/design/state?id=main` | документ |
| POST | `/design/state` | сохранить `{id, doc}` |
| POST | `/design/docs` | `create` / `rename` / `delete` |
| GET | `/design/models` | каталог моделей из профиля |
| POST | `/design/ai` | `{model, provider?, prompt, doc}` → `{ops, rejected}` |

Провайдер для `/design/ai` определяется по списку моделей профиля
(`dsh-home/profiles/desktop/cordis.patch.yml`): имя из `freepi` идёт в
`/freepi/v1/chat/completions`, из `freebuff` — в `/v1/chat/completions`. Токены и
устройство остаются внутри процесса: запросы уходят на собственный loopback-маршрут,
а не наружу.

Лог: `%APPDATA%\andrey-ds-harness\freebuff-route.log` (`design:save`, `design:ai`).

### Файлы

- `lib/andrey/design/ops.js` — схема документа и валидация (браузерная сборка).
- `lib/andrey/design/ops.cjs` — та же логика для Node.
- `lib/andrey/design/canvas.js` — движок канваса (рендер, ввод, история).
- `lib/andrey/design/panel.js` — панель, свойства, слои, документы, ИИ.
- `lib/andrey/design/panel.css` — стили (все классы `adz-`).
- `lib/andrey/ui-inject.cjs` — инжектит `panel.css`, затем `ops.js → canvas.js → panel.js → ui-renderer.js`.
- `lib/andrey/freebuff-route.cjs` — эндпоинты `/design/*`.

Все скрипты — обычные (без `import`/`export`), общаются через `window.AndreyDesign`.
## Пэт

В правом нижнем углу окна живёт «сгусток точек»: он показывает, чем занят агент, и
молчит, когда всё тихо. Состояния: `idle` — дышит, `working` — ускоренно вращается,
`replying` — пульсирует волной, `waiting` — тревожно мигает, `celebrate` / `error` —
короткие всплески. Состояние выводится из запросов страницы к LLM-маршрутам и лёгкого
опроса DOM; без сигналов пэт остаётся в `idle`.

- Пункт **«Скрыть пэта» / «Показать пэта»** в меню «…» — включение и выключение,
  выбор запоминается (`andrey-pet-enabled`).
- Перетаскивание — своя позиция (`andrey-pet-pos`), двойной клик — вернуть в угол,
  клик или Enter — короткая реакция и бабл со статусом.
- Файл: `lib/andrey/pet.js`, вставляется `ui-inject.cjs` вместе с `ui-renderer.js`.

## Провайдер Freebuff

Модели `freebuff` обслуживает собственный loopback-маршрут на `/v1/chat/completions`:
он поднимает официальный CLI в pty, выбирает модель в его пикере, отдаёт промпт
одной вставкой (bracketed paste) и читает ответ из транскрипта чата. Работает
строго через официальный клиент — сторонние клиенты Freebuff блокирует.

Настройки (переменные окружения процесса приложения):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `FREEBUFF_CWD` | пусто | рабочий каталог агента; пусто — приватный `freebuff-runs/<account>/<ts>` |
| `FREEBUFF_PROMPT_CHARS` | `24000` | сколько символов разговора уходит в CLI (новые реплики приоритетнее) |
| `FREEBUFF_SYSTEM_CHARS` | `4000` | сколько символов системного промпта идёт преамбулой `[System]` (`0` — выключить) |
| `FREEBUFF_RUN_TIMEOUT_MS` | `600000` | предел одного прогона; по нему отдаётся частичный ответ |
| `FREEBUFF_QUEUE_TIMEOUT_MS` | `900000` | сколько запрос ждёт очереди на аккаунт |

Поведение отказов: детерминированные состояния (лимит часов, подтверждение
трат, вопрос агента, не найден CLI) возвращаются как `409`, обрыв клиента — `499`,
остальное — `502`. Гейт доверия к `.agents`/`mcp.json` в рабочем каталоге получает
явный ответ «нет», чтобы TUI не зависал. Промпт уходит в TUI как обычные нажатия
(чанками по 200 символов): bracketed
paste до composers доходит, но CLI 0.2.36 выбрасывает внутри него переводы строк
(проверено: вставленный код приходит одной строкой), поэтому переносы
склеиваются в пробелы. Из промпта вырезаются управляющие символы (ESC и прочие
C0, кроме `\n` и `\t`): ESC превратился бы в нажатие Escape и сбросил бы ввод.
Токенов CLI не отдаёт, поэтому `usage` в ответах — оценка по длине текста
(кириллица ≈2 символа на токен, остальное ≈4), а не реальные числа провайдера:
тарификация идёт часами, а не токенами. Лог: `freebuff:request` /
`freebuff:prompt` / `freebuff:prompt-flattened` / `freebuff:usage-estimated` /
`freebuff:done` (с `reason` и `cwd`) / `freebuff:failed`.

## Автоматическое сжатие контекста

Длинная сессия раздувает массив `messages`, пока провайдер не отклонит запрос
или агент не начнёт терять нить. Перед отправкой маршрут freePi
(`freepi-route.cjs`) сжимает историю до бюджетного числа токенов: сохраняются
системные инструкции, первая реплика с целью и самые свежие ходы; вырезанные
серединой ходы заменяются одной короткой пометкой. Вызов инструмента и его
результат переносятся только парой — разорвать пару означало бы получить ошибку
`tool_call_id`, то есть как раз тот сбой, которого сжатие и должно предотвратить.

Оценка токенов приблизительная. Дополнительного запроса к LLM нет: у freePi
одна заявка в полёте, и второй запрос упирался бы в те же гейты, которые маршрут
уже обходит.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANDREY_CONTEXT_TOKENS` | `120000` | бюджет токенов истории freePi; при превышении история сжимается |
| `ANDREY_CONTEXT_ENABLED` | `1` | `0` — выключить сжатие, маршрут форвардит тело как есть |

Пока история в бюджете, тело запроса уходит байт-в-байт без изменений. Событие
`freepi:context-compressed` в `freebuff-route.log` показывает размеры до/после
и число вырезанных сообщений. У Freebuff своя обрезка — `FREEBUFF_PROMPT_CHARS`
(см. выше), — поэтому отдельный слой ему не нужен.
