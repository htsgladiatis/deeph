Подключить к приложению

Открой Andrey DS Harness → меню «Ещё» → «Браузер» и введи шестизначный код оттуда. Код одноразовый: после подключения расширение хранит только токен.

Нужно подтверждение

Вкладки агента

    Агент видит только вкладки в группе «Andrey Agent». Остальные вкладки, пароли и куки ему недоступны.

    Сайты

    Подтверждения по умолчанию: важные действия спрашиваются, обычные — нет.

    Разрешения задаются в приложении: «Ещё» → «Браузер» → «Сайты». Заблокированный сайт агент не тронет.
